## CS 2470 Deep Learning Final Project, Brown University

Deep Learning Final Project (Team LGD)

Team member: Wei Cheng, Minglang Yin, Enrui Zhang, Zongren Zou

### ac-ns
PINNs for solving forward problem of the Allen-Cahn Navier-Stokes equations.

### simplified NS
PINNs for solving for forward problem of simplified 2-D Navier-Stokes equations (flow around a cylinder)

### pinns-solids
PINNs for inferring a material property field for solids.

### exmaples
Illustrative examples of PINNs for solving time-independent and time-dependent Allen-Cahn Equation with physics-informed neural networks(PINNs).

### slides
Slides for deep learning presentation day.
